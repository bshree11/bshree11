## Featured Projects

### PayBridge — Payment Platform with AI Fraud & Compliance Controls
**Tech:** Node.js · TypeScript · PostgreSQL · Redis · React · Stripe · Razorpay · Claude AI · Docker

A UK/EU payments platform between merchants and processors, built with fraud and compliance controls at its core:

- **Fraud detection:** 7-rule scoring model combined with Claude AI, with approve / step-up 2FA / reject decision bands and fallback logic if the AI is unavailable
- **SAR reporting:** automatic Suspicious Activity Report triggers above the risk threshold
- **KYC / EDD:** onboarding and Enhanced Due Diligence workflows with User, Compliance Officer and Admin roles
- **Compliance:** PSD2 / SCA, UK GDPR and FCA rules built in: consent management, data export / erasure, 2FA and a 5-year append-only audit trail
- **Payments core:** double-entry ledger, daily settlement and reconciliation, multi-currency support and processor routing (Stripe + Razorpay) with automatic failover
